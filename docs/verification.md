# 検証レポート

## 305日目の東海道新幹線

公開ワーカーが使う列車計算を305日目のセーブに適用し、名古屋→東京は **5,410.493秒**、東京→名古屋は **5,407.353秒**（高需要）と確認した。名古屋→横浜は出発基準から **4,733.691秒**。照合済みの `.twtime` ではこれらの値を再現し、08:00出発指定の推定到着は09:39。運行間隔に基づく初回待ちは558.892秒。

通常のセーブでも、高速線路・速度制限と高需要の往復サイクルを反映すると、同じ系統の端から端は両方向で5,408.923秒。ゲーム計算値との差は両方向で2秒未満だが、通常ファイルでは駅間への配分を推定するため、名古屋→横浜は約2分26秒短く出る。この差を抑えるには `.twtime` を使用する。 [照合に使用した公式ワーカー](https://anita.garden/trainsworld/assets/clock.worker-hdc6c_8C.js)
